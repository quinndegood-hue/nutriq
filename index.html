📂 CSV import
Fitbit / Apple / Garmin
Export your data from the app and drop the CSV file here. NutriQ reads it automatically.
How to export:
⌚ Fitbit
fitbit.com → Log → Activities → Export → CSV. Or use the Fitbit app Data Export in Account settings.
🍎 Apple Health
Health app → Profile icon → Export All Health Data → share the ZIP → extract the CSV inside.
🟢 Garmin / Google Fit
Garmin Connect app → More → Data Export. Google Fit → takeout.google.com.
